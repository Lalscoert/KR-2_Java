# Практическая №5 — граничные проверки

Запуск: `javac -encoding UTF-8 -d out "@sources.txt"`, затем `java -cp out SelfCheck`.

| Сценарий | Ввод | Ожидание |
|---|---|---|
| Типовой | `8;8;9;10;7` | сумма 42, среднее 8.4, переработка в 2 дня |
| Нижняя граница | `0;0;0;0;0` | сумма 0 |
| Верхняя граница | `16;16;16;16;16` | сумма 80 |
| Ровно 8 часов | `8;8;8;8;8` | 0 дней с переработкой |
| Пустая строка | пустая | контролируемая ошибка |
| Выше максимума | `8;8;8;8;17` | ошибка позиции 5 |
| Меньше нуля | `8;-1;8;8;8` | ошибка позиции 2 |
| Не число | `8;8;abc;8;8` | ошибка позиции 3 |
| Мало полей | `8;8;8;8` | ошибка количества |
| Пустое поле | `8;8;8;8;` | ошибка позиции 5 |

`SelfCheck` содержит 12 проверок. Он завершает программу с кодом `1`, если обнаружил ошибку.
